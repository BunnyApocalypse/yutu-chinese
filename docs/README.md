# How the app works, area by area

CLAUDE.md keeps the rules and points here. Each file has what an area does now, the names in the code, and the owner's decisions with their dates.

| File | What it covers |
|---|---|
| `words.md` | Adding words, the dictionary and search, scripts, Taiwan and mainland readings |
| `cards.md` | Card kinds, FSRS, grading, Learn and the lesson, writing cards per script, leeches, managing cards, streaks |
| `decks.md` | The Decks tab, adding, how decks work, ready-made decks |
| `word-lists.md` | HSK, TOCFL, groups, reading fixes, radicals |
| `anki.md` | Importing from Anki: reading the file, the guesses, keeping schedules |
| `merging.md` | What is kept for merging, combining backups |
| `word-page.md` | The word page, sentences, hearing a word |
| `writing.md` | Raw input, shortcuts, following the frame, two stroke orders, the stroke count, gestures |
| `pitfalls.md` | Things that are easy to get wrong |
| `offline.md` | The two copies, the service worker, icons, the old address |
| `interface.md` | Introduction, storage, tips, menu, tabs, practice, Settings, pop-ups, What's new, wording, sizes, looks, accessibility |
| `ux-review.md` | The screenshot atlas, and what the review of 2026-10-16 led to |
| `layout.md` | Every file, one line each |
| `goals.md` | Long-term goals, sharing the app, Skritter import, translations |
| `history.md` | The latest handover, the roadmap, the testing sessions |

Also: `alpha/` (what testers were given), `../tests/browser/CLAUDE.md` (browser tests), `../data/notes/CLAUDE.md` (writing learning notes).

**Keeping these up to date:** when something is built or changed, write the decision into its area's file: what it does, the names in the code, the owner's choice with its date. Say what is true now, not how it came about; git has that. Replace what a change makes untrue rather than adding "since…" after it.
